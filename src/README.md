# Smart Analytics Panel

Smart Analytics Panel is a Grafana panel plugin designed to provide quick analytics, anomaly detection, and trend insights directly inside Grafana dashboards.

The plugin helps users better understand time-series data by combining visualization with lightweight analytical insights such as:

- Trend detection
- Anomaly highlighting
- Statistical summaries
- Series-level monitoring

It is built to work naturally inside Grafana while maintaining performance and compatibility with both light and dark themes.

---

## Features

- Interactive time-series visualization
- Lightweight anomaly detection
- Min / Max / Average statistics
- Trend analysis support
- Fast rendering for dashboard workflows
- Grafana theme compatibility
- Easy integration with existing dashboards

---

## Requirements

- Grafana >= 10.0.0

---
